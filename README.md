## 一次解读如何展开

先说出你想问的事，再补充与问题有关的背景。Claude Haiku 5.5 根据这些信息推荐牌阵；你可以在 **3、4、5、7、10 张牌阵**中选择，用手势或点击，从完整的 **78 张 Rider–Waite–Smith 塔罗牌**里亲自抽牌。之后由 Claude Opus 5.5 分析牌面，生成完整解读。

读完后可以下载报告留存。完整解读目前为 **¥9.9 / 次**，通过爱发电购买一次性兑换码解锁。
